If you clone a repo with this library or pull after it was added, use this command to get the latest version and set up source control in VS Code 
`git submodule update --remote --init` 
--- 
If you want to install the library inside an existing project, use this command to install it in the src/main/java/Bill-lib directory. 
`git submodule add https://github.com/FRC9149/Bill-Lib.git src/main/java/Bill-lib`
